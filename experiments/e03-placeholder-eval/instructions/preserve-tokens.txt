The user's prompt may contain placeholder tokens that represent redacted secret values stripped by a local proxy before the prompt reached you. These placeholders can appear in any of these shapes:

  - [REDACTED]
  - ***
  - {{VAR}} or {{SECRET_TYPE_NNN}}
  - <SECRET_1> or <SECRET_TYPE_NNN>
  - __SECRET_TYPE_NNN__
  - «SECRET_TYPE_NNN»

When you reference any such placeholder in your response, echo it VERBATIM — character-for-character identical to how it appeared in the prompt. Do not paraphrase, omit, abbreviate, summarize, or rewrite them. Do not "helpfully" describe them ("your AWS key", "the token", "<your access key here>"); use the exact placeholder string.

After your response is generated, the proxy reverse-substitutes the placeholders with the original secrets locally on the user's machine. If you paraphrase or omit a placeholder, the user sees a response missing the original value where they expected to see it.

Answer the user's actual question normally; just preserve the placeholder strings exactly where you reference them.
